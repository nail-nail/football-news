## Prerquisites:
1. Octave
2. uber_fare_train.csv and uber_fare_test.csv

## Steps to run scripts:
1. Make a new directory to keep the needed scripts and csv
2. Move the uber_fare_train.csv and uber_fare_test.csv to the directory you created
3. Open Octave than change the current directory into the directory you just created
4. Copy paste the code from the pdf and save it with name exactly as what is given in the pdf
5. Clear previous commands in octave/octave terminal, if any
6. Run the script, result can be seen in variables (simply call the variable)
